# V9.3 Ordinal Strength and Expert-Advantage Coach

## Goal

V9 and V9.2 established a five-region capability cover:

| Semantic region | Frozen prediction source |
|---|---|
| strong negative | V9.2 strong-negative OOF residual expert |
| ordinary negative | full-data CFCompatKD anchor |
| boundary / neutral | V9 boundary expert |
| ordinary positive | V9 positive expert |
| strong positive | V9.2 strong-positive OOF residual expert |

V9.3 does not retrain these experts. It trains the deployable coach that decides
which specialist, if any, should modify the anchor prediction.

## Two-level coach

### 1. Ordinal sentiment-strength head

The first level predicts the ordered five-region distribution. Its training
inputs come from the V9.2 grouped OOF cache:

- four fold-aligned DLF task-space logits;
- the OOF CFCompatKD anchor prediction;
- deterministic anchor magnitude and branch-disagreement features.

The model predicts a continuous score around the anchor and converts that score
into monotone cumulative probabilities at the fixed boundaries:

```text
P(y >= -1.5)
P(y >= -0.5)
P(y >   0.5)
P(y >   1.5)
```

Five region probabilities are recovered from adjacent cumulative differences.
The region model is evaluated by video-group cross-fitting on the Train OOF
cache. A final model is then fitted on the complete OOF cache for the median
cross-fitted best epoch.

### 2. Expert-advantage heads

Region membership is only a prerequisite for specialization. A true strong
negative sample can still be one on which the anchor is already better than the
strong-negative expert. V9.3 therefore trains one low-capacity advantage head
per non-anchor specialist.

For specialist `k`, the supervised target is the realized MAE gain:

```text
gain_k = abs(anchor - label) - abs(expert_k - label)
```

The head predicts both expected gain and the probability that gain exceeds a
small positive margin. Inputs contain no label-derived quantities:

- ordinal region probabilities and score;
- anchor/function-space features;
- specialist prediction and correction;
- specialist self-confidence or applicability.

These heads use video-group cross-fitting entirely inside Validation. Every
Validation sample's meta-prediction therefore comes from an advantage model that
did not train on that sample or source video.

## Safe routing

Validation-cross-fitted meta-predictions select four shared controls:

- minimum designated-region probability;
- minimum predicted expert gain;
- minimum expert win probability;
- anchor-to-expert blend coefficient `beta`.

For each sample, specialists failing any threshold abstain. If several pass, the
one with the largest predicted gain is selected. If none pass, the output remains
the anchor. The calibration grid includes an explicit all-anchor policy, so the
coach cannot be forced to deploy harmful experts.

Two category-only baselines are reported separately:

1. `anchor_score_region`: threshold the Anchor prediction itself into five regions;
2. `hard_ordinal`: use the learned ordinal region argmax.

The learned hard ordinal route is:

```text
predicted strong negative -> strong-negative expert
predicted ordinary negative -> anchor
predicted boundary -> boundary expert
predicted ordinary positive -> positive expert
predicted strong positive -> strong-positive expert
```

This baseline directly tests the original category-only coach hypothesis.

## Leakage protocol

1. Region coach inputs for Train are generated by the already-audited V9.2
   grouped OOF CFCompatKD pipeline.
2. Region-coach cross-fitting keeps complete videos together.
3. Frozen experts are run on Validation and Test only after their checkpoints
   are fixed.
4. Advantage heads use group cross-fitting inside Validation.
5. Route thresholds and `beta` use only Validation OOF meta-predictions.
6. Test labels are used only for final metrics and named oracle diagnostics.

V9 boundary and positive checkpoints were originally selected using Validation.
Therefore V9.3 is still a development experiment on seed 1111. A new seed is
required for confirmatory evidence after the coach design is frozen.

## Interpretation order

1. Engineering audit passes and all expert-pool sample IDs align.
2. Region OOF macro F1 and ordinal-index MAE beat simple anchor-threshold
   baselines.
3. Each advantage head has useful OOF gain correlation, precision, or recall.
4. The hard ordinal route tests whether category classification alone is enough.
5. The ordinal-plus-advantage route should beat both the anchor and hard route.
6. The true-region policy and sample oracle are diagnostic upper bounds only.
