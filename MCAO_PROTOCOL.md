# Stage 17 MCAO Protocol

Stage17 first audits the actual CFCompatKD training objective and runtime
gradients. Presence masking and availability normalization are permitted only
if missing-modality auxiliary losses remain active with material scalar and
gradient contributions in both preregistered audit seeds.

MCAO changes training objectives only. It cannot add inference parameters,
modules, FLOPs, teachers, adapters, prototypes, context, dynamic weighting, or
test-guided choices.
